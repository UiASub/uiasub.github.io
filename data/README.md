# Info for data/

## members.json

Both About pages load this roster automatically. Use full names and stable, unique
IDs. Set `group` to `board` for everyone with a board role; other members belong
to their department (`data`, `electronics`, `mechanical`, or `marketing`).
`role_no` and `role_en` provide the displayed role in each language.

Set `image` to a filename in `images/profie_shared/`, or `null` when a member has
no photo. Missing photos display a translated “photo coming soon” placeholder.

See <https://wiki.uiasub.no/website/reference/member-data-management/> for documentation.
